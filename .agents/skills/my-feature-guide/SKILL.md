# 기능안내 기존 호출 연결

`/기능안내` 또는 `$my-feature-guide` 요청을 기존처럼 받을 때 [my-communication](../my-communication/SKILL.md)을 읽고 사용자 요청에 맞는 설명을 제공한다. 독립 R6를 통과한 기능의 기본 안내는 소통의 [기능안내 모드](../my-communication/references/feature-guide.md)를 따른다. 작업 중 질문과 명시적 안내 요청은 현재 확인한 근거로 바로 답하며 미완료·미검증을 구분한다.

시험·평가 제한이 안내에 우선한다. 하이닉스 시험에서 제출물 확정 뒤 후속 서술형 단계에는 설명·답변 생성·첨삭·코칭을 중단한다. 단계가 불명확하고 실제 평가 문항으로 보이면 먼저 단계를 확인한다. 최신 규정은 [hynix-exam-guide](../hynix-exam-guide/SKILL.md)를 따른다.

[제작 배경](references/design-context.md)은 기존 기능안내의 만든 니즈·선례·변형 이유를 검토할 때 읽는 기록이다.
