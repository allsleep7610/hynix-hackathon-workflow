# 제작 배경

이 문서는 제작 이유와 참고 기반의 기록이며 실행 지침이 아니다. 합의한 방향을 실제 문안으로 작성했고, 사용자가 아직 이 판본을 검토하지 않아 draft로 둔다.

## 만든 니즈

사용자는 하이닉스 시험에서 핵심 동작·기능을 본인이 이해하고, 사람이 실제 확인한 내용도 구별해 설명하고 싶다고 했다. 선례를 조사한 뒤 필요한 부분만 기존 워크플로우에 병합하도록 요청했다. 이후 사용자 할 일을 만들려고 AI가 수행할 테스트를 생략하거나 넘기는 방향을 명시적으로 배제했다. 이 Skill은 구현·검증을 계속 수행하면서 독립 R6 통과 뒤 확인된 기능을 안내하고 작업 중 질문에는 바로 답해 이해와 활용을 돕도록 작성했다. 사용자는 검토를 통과한 판본에 안내를 맞추기 위해 기본 시점을 R6 뒤로 옮기고 출력 형식을 합의했다.

공개 지침의 패턴을 확인해 현재 사용자 합의와 기존 Skill 책임에 맞게 재서술했다. 외부 파일·설치기·코드를 복사해 실행하지 않았고, 선례의 시험환경 작동·학습효과·채점상 이점은 검증하지 않았다.

## 작동 방식

메인은 핵심 기능에 대한 독립 R6 통과 결과를 받은 뒤 해당 범위·판본의 기능안내를 연결한다. 보완이면 R5 수정·검증과 R6 재판정으로, 재정렬이면 필요한 방향 판단으로 연결한다. 작업 중 질문·명시적 안내 요청과 사람만 가능한 필수 선행 확인은 필요한 시점에 안내한다. 기본 출력은 사용할 수 있게 된 기능→핵심 동작→사용 방법→검증 범위·한계이며, 실제 입력·처리·출력과 중요한 선택 이유를 연결한다. 특정 질문에는 관련 답만 제공한다. 직접 사용은 필요하거나 사용자가 원할 때 안내하며, 응답 대기를 새 필수 단계로 만들지 않는다. 규정·명세·도구상 사람만 확인할 수 있는 항목은 이유와 범위를 분리해 남긴다. 관찰 피드백이 생기면 기존 작업 기록에 출처·범위를 연결한다.

## 주의점

AI의 구현·필요 검증 책임은 유지한다. 사용자가 써보지 않아도 유효한 AI 검증을 취소하지 않으며, AI 검사나 설명 제공을 사람의 직접 확인·이해 완료로 표시하지 않는다. 관련 변경 뒤 근거의 적용 범위를 살피고 R6 독립 판정을 대신하지 않는다. 실제 시험환경의 Skill 발견·도구 지원과 사용자의 이해 개선은 별도 확인이 필요하다. 제출물 확정 뒤 후속 서술형에서는 설명·답변·첨삭·코칭을 중단하고 문제·작업·결과를 외부로 보내지 않는다.
