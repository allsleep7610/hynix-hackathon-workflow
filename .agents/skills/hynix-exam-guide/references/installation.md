# 하이닉스 하네스 설치 요청의 마무리

사용자는 “하이닉스 하네스 설치해줘”처럼 짧게 요청한다. 이 저장소의 설치·재적용 요청을 받으면 기존 반입·배치 방법으로 하네스를 적용한 뒤 아래 설정 변경·도구 확인·결과 보고까지 이어간다. 일반 과제 요청이나 매 입력의 반복 절차로 만들지 않는다.

## 설치와 적용 확인

저장소는 `allsleep7610/hynix-hackathon-workflow`이다. 제공 환경의 허용 경로와 기존 설치 방법을 유지하고 작업공간·실제 배치 위치·AGENTS와 Skill 인식 상태를 확인한다. 기존 파일과 SESSION 정본을 보존하며 필요한 공식 Skill이 이미 제공되면 사용 가능한 것을 확인해 활용한다. 자동 인식을 확인하지 못하면 필요한 지침을 직접 읽은 범위를 알린다. Hook은 기존 runtime 안내에 따라 선택 연결하고, 미지원이면 SESSION 직접 조회·저장으로 이어간다. 설치를 이유로 과제를 시작하거나 불필요한 도구를 새로 설치하지 않는다.

## 설치 후 현재 세션 설정 변경

**사용자 선택 — 설치 후 설정:** 모델은 GPT-6.1 Sol(`gpt-6.1-sol`), 추론은 High, 접근 권한은 Full access, 속도는 Fast로 맞춘다. 이는 이 하네스 설치 요청의 후속 선택이며 일반 R4의 하위 작업 설정 계승 규칙은 유지한다.

현재 제공된 설정 변경 도구·지원 명령·화면 중 실제 허용 경로를 확인한다. 직접 변경할 수 있는 항목은 적용하고 현재 활성 세션의 값을 다시 읽어 확인한다. 직접 할 수 있는 항목을 확인·설명만 하고 끝내지 않는다. 지원되지 않거나 정책에 막힌 항목은 나머지 가능한 작업과 분리해 진행하고, 필요한 사용자 조작을 마지막에 짧게 안내한다. 설정 화면을 AI가 조작할 수 없는 경우에는 사용자에게 해당 조작을 안내한다. 관리 정책·인증·계정 설정을 바꾸거나 제한을 우회하지 않는다.

설정 파일을 쓴 사실만으로 현재 모델·권한·속도가 바뀌었다고 표시하지 않는다. 재읽기·재개가 필요하면 그 방법과 현재 적용 여부를 구분한다. 다음 세션까지 유지되는지는 실제 확인 전에는 미확인으로 남기며, 영구 설정을 만들기 위해 개인 홈의 기존 설정을 덮어쓰지 않는다. 현재값을 읽을 수 없으면 적용 미확인으로 보고한다.

## 자연어 세션 분기 도구 확인

현재 에이전트에 제공된 도구 목록·명세에서 기존 대화를 새 사용자 대화로 분기하는 기능이 있는지 확인한다. 있으면 도구명과 지원 범위를, 없으면 제공되지 않음을, 목록을 볼 수 없거나 기능이 불명확하면 미확인을 보고한다. `/fork` 사용자 명령의 존재나 서브에이전트 생성 기능만으로 자연어 사용자 대화 분기 도구가 있다고 판정하지 않는다. 이 설치 요청에서는 실제 새 대화를 만들지 않는다. 분기가 별도로 요청되면 지원 경로로 수행하고 생성된 세션·작업 위치를 확인한다. 직접 조작만 지원되면 해당 환경에서 지원하는 사용자 조작과 인계 내용을 안내한다.

## 결과 보고

설치·적용 결과, 설정 네 항목의 실제 적용값, 자연어 분기 도구 확인 결과를 짧게 보고한다. 완료한 것과 못 했거나 확인하지 못한 것·이유를 구분하고, 사용자가 해야 할 조작이 있으면 함께 제시한다. 모든 항목이 성공한 것처럼 묶어 완료 처리하지 않는다. 실제 토큰·인증·전체 설정·시험 내용은 출력하거나 공개하지 않는다.

설정·분기 기능의 제공 여부는 환경마다 다르다. 터미널 개수를 사용자 대화나 서브에이전트 수로 바꾸어 해석하지 않는다. 이 설치 후 흐름은 새 세션 전체의 권한이나 실제 시험 환경의 지원을 보장하지 않는다.
