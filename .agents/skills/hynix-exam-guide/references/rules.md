# 도구·자료·AI 단계·전송 규정

적용 대상은 2026 SK하이닉스 AI 해커톤 2차 예선이다. 출처와 판본 관계는 [sources.md](sources.md)를 따른다.

## AI와 제공 도구

| 구분 | 적용 기준 |
|---|---|
| 과제풀이 AI | 응시 환경에 제공된 Codex를 사용한다. 개인 API 키·개인 유료 구독·Claude Code·별도 외부 AI 모델 연결은 허용되지 않는다. |
| 모델 | Astra 사용은 제한된다. 10월 29일 안내의 권장 모델은 Sol 6.1, Terra 5.6, Luna 6.0이다. 권장 목록을 사용 가능한 모델 전체나 세 모델만의 허용 목록으로 해석하지 않는다. |
| Codex 판본 | 제공된 Codex를 업데이트하지 않는다. |
| Skill·MCP·Plugin | 공개된 자료·도구를 과제에 필요한 범위에서 활용할 수 있다. 적용 방법은 제공 환경의 안내와 실제 허용 범위를 확인한다. |
| MCP 설정 | 플랫폼 MCP 탭에서 제공하는 서버 설정 JSON 편집·저장은 공식 안내에 포함된다. 이를 플랫폼 관리 설정 변경과 일괄적으로 같은 행위로 취급하지 않는다. |
| 작업 문서 | 과제에서 요구한 계획 문서·협업 기록 등은 코딩 에이전트와 작성할 수 있다. 선택한 판단·근거·검증 결과·남은 한계를 실제 작업과 맞춘다. |
| 후속 서술형 | AI와 복사·붙여넣기를 사용할 수 없다. 외부 브라우저나 다른 기기의 AI도 금지된다. 해당 단계에서는 답변 생성·작성·검토 지원을 중단하고 본인이 직접 답변한다. |

토큰 사용량은 추적되며 간접 평가에 활용될 수 있다고 안내되어 있다. 이 사실에서 특정 모델의 배점이나 숨은 평가 기준을 추정하지 않는다.

## 공개 자료와 반입

| 상황 | 적용 기준 |
|---|---|
| 공개 GitHub 자료 가져오기 | 공개 저장소의 지침·Skill·하네스·템플릿·코드를 상세 가이드의 허용 범위에서 활용할 수 있다. Git Clone·다운로드와 외부 전송을 구별한다. |
| 공개 상태 유지 | 사용하는 공개 저장소는 결과 통지 전까지 공개 상태를 유지한다. 별도 등록 절차나 사전 최소 공개 기간은 10월 29일 메일에 명시되지 않았다. |
| 비공개 저장소 | 사용할 수 없다. 개인 PC의 비공개 Skill이나 파일을 업로드하는 방식으로 가져오지 않는다. |
| 외부 코드·자료 활용 | 소스코드 참고와 일부 알고리즘 차용은 가능하다. 외부 자료로 결과물을 통째로 대체하지 않는다. |
| 정보 습득 | 제공 플랫폼 안에서 AI를 통해 필요한 공개 정보를 습득·활용한다. 외부 브라우저의 직접 접근 제한을 따른다. |

공개 자료 활용 허용은 참가자에게 온 메일 전체의 재배포 허락을 뜻하지 않는다. 이 참조에는 공통 운영 사실만 짧게 재서술한다. 개인 접속 정보·코드·수신자·메일 헤더·실제 문제·답안·데이터·SESSION 원문을 포함하지 않는다. 모든 수신 자료가 비밀이거나 모든 요약에 운영팀 허락이 필요하다고 일괄 단정하지 않는다.

## 외부 전송과 운영 영역

| 상황 | 조치 |
|---|---|
| 문제·파일·작업 결과물을 외부로 보내려는 경우 | 외부 전송·공유 금지 규정을 적용한다. Git Push는 불가능하며, 공개 자료를 가져오는 Clone과 구별한다. |
| 개인 PC 파일을 업로드하려는 경우 | 업로드할 수 없다. 필요한 작업 파일은 제공된 작업 공간 안에서 작성한다. |
| 차단·업로드 제한 때문에 다른 경로나 설정을 쓰려는 경우 | 제한 우회를 시도하지 않는다. 오류는 시험 환경의 신고 기능으로 접수한다. |
| 플랫폼 관리 설정·연결 프로세스를 바꾸려는 경우 | 수정·종료하지 않는다. 키·토큰도 공개하지 않는다. |
| Computer Use로 자동 조작하려는 경우 | 전 단계 사용 금지 규정을 적용한다. 플랫폼 Browser의 사람 직접 확인과 AI 자동 조작을 구별한다. |
| 다른 사람의 도움이나 공동 풀이를 받으려는 경우 | 대리 수행, 답안·풀이 지시 전달, 응시자 간 답안 교환·공동 풀이는 허용되지 않는다. |

경고나 의심 정황만으로 탈락을 확정하지 않는다. 가이드는 직접 확인된 제한 위반과 추가 사실 확인이 필요한 상황을 구별하며, 최종 운영 판단은 관련 기록과 상황을 종합해 이루어진다고 설명한다.
