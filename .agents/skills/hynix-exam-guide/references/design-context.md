# 제작 배경

이 문서는 실행 지침이 아니라 만든 이유와 방식을 설명하는 제작 배경이다. 2026-10-29 확인 자료를 바탕으로 네 항목을 작성했으며, 사용자가 실제 원고를 확인하기 전이므로 상태는 `draft`이다. 실제 설치·공개·시험 반입·환경 작동 검증은 이 문서의 작성 완료와 구별한다.

## 만든 니즈

사용자는 기존에 유지하기로 한 16개 Skill에 대회 정보 참조 1개를 더하는 구성을 선택했다. 범용 시험 문맥용 Skill을 따로 추가하는 대신, 이번 2026 SK하이닉스 AI 해커톤 2차 예선에서 실제 판단을 바꾸는 규정·환경·저장·제출 정보를 한곳에서 필요할 때 조회하려는 목적이다.

기존 R1~R6의 작업 책임, 권한 판단, SESSION 관리에 대회 안내를 중복 삽입하면 같은 내용을 여러 곳에서 관리해야 한다. 이 Skill은 그 절차를 재설계하지 않고 해당 판단에 필요한 대회 사실만 공급한다.

## 참고 기반

| 기반 | 제작에 사용한 방식 |
|---|---|
| 단계별 정보 조회 | 공식 Skill 제작 지침의 점진적 정보 제공 방식을 적용했다. 본문에는 역할·적용 조건·참조 연결을 두고, 도구 규정과 환경·제출 정보를 상황에 따라 조회한다. |
| 출처와 적용 범위 구분 | 최신 안내를 무조건 전체에 덮어쓰지 않고, 같은 사항의 수정인지·다른 단계의 안내인지 대조하도록 했다. 문서 확인과 실제 실행 검증도 구별했다. |
| 실제 제공 환경 | 일반적인 로컬 개발 환경을 가정하는 대신 제공 Codex·MCP 탭·Browser·메신저·저장 표시·제출 고정·후속 서술형으로 행동을 연결했다. |
| 사용자 지침 작성 기준 | `my-llm-prompt-guide`와 작성·수정 기준에 따라 의도·적용 범위·주의점을 남겼다. 기본 책임을 모델 결함 보완으로 재해석하지 않았다. |

운영 사실의 입력 자료는 [sources.md](sources.md)에 기록한 메일·공식 가이드·공식 소개이다. 이 입력 자료와 위의 설계 방법을 같은 종류의 참고 기반으로 혼동하지 않는다.

## 작동 방식

현재 요청에서 대회 조건이 행동을 바꾸는지 먼저 판단한다. 해당하는 경우 AI·자료·전송 조건은 `rules.md`, 사람의 준비·도구 사용·저장·제출은 `platform.md`, 출처 충돌과 확인 상태는 `sources.md`의 관련 절을 조회한다.

예를 들어 공개 하네스를 가져올지 판단할 때에는 공개 상태 유지·Clone과 Push·업로드 제한을 확인한다. Browser 연결 실패라면 실제 포트·바인딩·경로를 확인한다. 저장 충돌이 생기면 에디터와 작업 공간 내용을 비교한 뒤 선택한다. 제출 전에는 파일 저장과 확정 이후 수정 불가 조건을 확인한다.

후속 서술형으로 넘어가면 허용 조건이 바뀐다. 과제풀이에서 가능했던 AI 문서 작성 도움을 이어가지 않고, 응시자가 직접 답변하도록 지원 범위를 종료한다.

## 주의점

- 이 Skill은 개인 참조 후보이며 공식 규정이나 실제 과제 안내를 대체하지 않는다. 공개 목적·평가 방향을 배점이나 숨은 기준으로 확장하지 않는다.
- 권장 모델을 허용 모델 전체로 만들지 않는다. 제공 Codex 업데이트 금지와 휴대폰 Proctor 업데이트·재설치 안내를 구별한다.
- 공개 자료 활용 허용과 외부 전송 허용을 구별한다. 참가자 메일 전체의 재배포 권한을 추정하지 않으며 개인 연결 정보나 실제 문제·답안·데이터를 담지 않는다.
- MCP 탭의 공식 설정과 플랫폼 관리 설정 수정을 구별한다. Browser의 사람 직접 확인과 금지된 Computer Use 자동 조작도 구별한다.
- Skill 인식·파일 지속성·Node/helper·독립 평가자 지원은 검증 전까지 미확인으로 둔다. 플랫폼 업무 에이전트의 존재를 Codex 내부 평가자 지원으로 해석하지 않는다.
- 기존 절차·권한·SESSION 책임은 해당 담당 지침에 남긴다. 대회 정보 참조를 모든 입력에서 자동으로 전수 로딩하는 공통 규칙으로 넓히지 않는다.

이 원고에는 확인된 모델·버전의 결함을 전제로 한 모델 보완 지침을 추가하지 않았다. 규정과 출처 구별은 이 Skill의 기본 책임이며, 참조 전용 범위와 기존 16개 유지 구성은 이번 사용자 선택을 반영한다.
