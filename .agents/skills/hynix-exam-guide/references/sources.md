## 판본을 적용하는 방법

| 차이 | 적용 |
|---|---|
| 최신 메일과 기존 가이드가 같은 사항에서 충돌 | 10월 29일 메일을 우선한다. |
| 최신 메일이 기존 사항을 언급하지 않음 | 기존 가이드의 해당 조건을 유지한다. |
| 상세 가이드가 Chrome 또는 Edge를 제시하고 최신 메일이 Chrome을 지정 | Chrome을 사용한다. |
| 기존 권장 모델 목록에 Sol 6.0이 있고 최신 메일의 권장 목록이 달라짐 | 최신 권장 목록을 제시한다. 권장 여부와 사용 가능 여부는 구별한다. |
| 가이드의 당일 추가 메일 시각과 최신 메일의 시각이 다름 | 최신 메일의 당일 09:40 안내를 적용한다. |
| 안내 화면의 예시 문항 수와 시험 공지의 6문항이 다름 | 예시를 실제 조건으로 삼지 않는다. 공지와 실제 응시 화면의 적용 범위를 확인한다. |
| 일반 가이드와 실제 과제의 목표·필수 파일이 다름 | 실제 과제 README·과제 안내를 기준으로 한다. 운영·보안 규정은 별도로 유지한다. |
| 문서가 더 최신이지만 대상 단계·행위가 다름 | 날짜만으로 다른 범위의 조건을 덮어쓰지 않는다. |
| 적용 범위까지 대조해도 충돌이 남음 | 충돌과 미확인 사항을 밝히고 허용된 담당 경로로 확인한다. 임의로 허용·금지를 추가하지 않는다. |

## 확인 상태와 한계

| 항목 | 상태 |
