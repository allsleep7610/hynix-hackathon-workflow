# SK하이닉스 AI 해커톤 2차 예선 안내 참조

2026년 2차 예선의 운영 조건을 필요한 순간에 확인하여, 허용된 작업을 제공 환경과 제출 절차에 맞게 진행하도록 돕는다. 이 문서는 참가자 안내를 짧게 재서술한 개인 참조 후보이며 공식 안내를 대신하지 않는다.

## 적용과 책임

현재 요청에서 대회 규정·환경·저장·제출 조건이 행동 선택을 바꾸는 경우에만 관련 참조의 해당 절을 읽는다. 대회 이름이 등장했다는 이유로 참조 전체를 읽거나 일반 코딩에 매번 적용하지 않는다.

기존 작업 흐름의 문제 정의·목표·명세·실행·평가 및 권한 판단은 각각의 담당 지침을 따른다. 이 Skill은 R1~R6 절차나 SESSION 갱신을 추가하지 않으며 응시·접속·문의·자료 공개의 실행 권한을 새로 부여하지 않는다.

먼저 현재 단계가 사전 준비, 사전 체험, 과제풀이, 제출물 확정, 후속 서술형 중 어디인지 구별한다. 후속 서술형의 AI 사용 금지 단계에 들어가면 이 Skill을 이용한 답변 생성·작성·검토 지원을 중단하고 응시자가 직접 답변하도록 안내한다.

## 필요한 정보만 조회

| 사람의 사전 준비, 제공 도구, Browser, 저장 충돌, 시간·제출·종료 | [환경과 진행](references/platform.md)의 관련 절 |
| 안내 간 차이, 출처·판본·확인 범위, 미확인 조건 | [출처와 적용 범위](references/sources.md) |
| 이 Skill을 만든 이유나 범위를 검토·수정 | [제작 배경](references/design-context.md) |

과제의 목표·필수조건·필수 파일은 실제 과제 README와 과제 안내를 확인한다. 사용법 가이드의 예시 화면·파일명·문항 수를 실제 과제 요구로 옮기지 않는다.

안내가 다르면 날짜와 함께 적용 대상·단계를 대조한다. 10월 29일 메일이 기존 가이드의 같은 사항을 수정한 경우 메일을 따르고, 언급하지 않은 사항은 기존 가이드를 유지한다. 다른 범위의 내용을 날짜만으로 덮어쓰지 않는다.

확인된 운영 사실과 실제 환경 검증 결과를 구별한다. Skill 인식 경로·파일 지속성·실행 도구·독립 평가자 지원은 확인 전까지 미확인으로 남기며, 안내에 예시 명령이 있다는 이유로 지원을 보장하지 않는다.
