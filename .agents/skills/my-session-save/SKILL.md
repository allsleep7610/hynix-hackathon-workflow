# 세션 확정 산출물과 현재 상태 보존

문제·목표·계약·실행 구조가 모두 다음 판단의 근거이므로 시험 플랫폼이 제공한 작업공간 안에서 해당 세션의 `SESSION.md` 위치를 정해 단일 정본으로 사용한다. 다른 세션의 문서를 자동 상속하거나 프로젝트 정본과 동기화하지 않는다. 현재 버전의 완전한 전체 문서가 이미 문맥에 있으면 중복 조회하지 않고 현재 요청·확인된 대화와 대조한다. 시작·재개·맥락 압축 후, 누락·잘림·오류·상태 충돌이 있으면 필요한 원문을 직접 읽어 공백을 보완한다. 파일 존재·입력·상태 표시는 목표·완료·권한을 판정하지 않는다.

갱신 질문은 하나다. **이 문서를 그대로 두면 다음 판단이나 행동을 잘못하게 되는가?** 단계가 확정·변경되거나 의미 있는 실행 결과가 있으면 영향받는 구획만 갱신한다. 매 답변·도구 호출·작은 진척마다 저장하지 않는다.

정본에는 현재 상태와 R1~R4 확정 산출물 전체를 둔다.

단계 원문을 재요약하거나 내부 제목·표·코드를 양식에 맞춰 바꾸지 않는다. 해당 단계가 실제로 확정한 내용만 넣고 아직 없는 단계는 미확정으로 표시한다. 원문 안의 가설·잠정·미확인도 그대로 보존한다. 현재 상태는 위치·다음 행동·잠정·미결정·필요한 증거를 관리하며 목표·계약의 또 다른 요약 정본을 만들지 않는다.

R1~R4는 자기 산출물의 의미를 소유하고 R5는 실제 결과 뒤 R4의 완료·현재 위치·남은 흐름을 갱신한다. 상위 단계가 바뀌면 하위 계약·계획의 유효성을 대조하고 필요한 재정렬을 현재 상태에 표시한다. 국소 통과를 세션 전체 완료로 바꾸거나 승인 범위를 넓히지 않는다. 저장 뒤 원문·결정·판정 범위를 대조한다.

보존·갱신·복원·구형 문서 전환에는 [SESSION 규격](references/session-document.md)을 따른다. 정해진 경계는 원문 바깥에만 두며, 읽은 버전을 대조하고 잠금과 원자적 교체로 다른 구획을 보존한다. 메인이 세션 정본을 통합 관리하며 분기는 자기 문서를 관리한다. 증거·복구 자료는 참조할 수 있지만 별도 R4나 단계 파일을 또 하나의 현행 정본으로 관리하지 않는다. 원문이 없거나 충돌하면 확인 가능한 것만 복원하고, 중요한 미확인 결합·변경은 영향받는 실행 전에 사용자 판단을 받는다.

사용자가 세션 마무리를 뜻하면 현재 상태를 정리하고 프로젝트에 인계할 내용·여부를 확인한다. 이미 대상·범위·승인이 분명하면 다시 묻지 않는다. 명시적 승인 범위에서만 지정 프로젝트 문서에 선별 반영하며, 거절하거나 답이 없으면 프로젝트에는 쓰지 않는다. 세션 문서는 삭제하지 않는다. 소통 Skill은 이 문서를 읽거나 갱신하는 경로가 아니다.
