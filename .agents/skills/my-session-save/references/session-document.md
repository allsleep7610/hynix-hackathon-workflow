# SESSION 단일 정본 규격

단계 산출물을 보존·갱신하거나 복원·전환할 때 읽는다. 일반 작업에서 매번 이 규격을 출력하지 않는다. SESSION은 세션 판단 근거이며 프로젝트 개발 원본이나 실행 승인 원장이 아니다.

## 원문과 바깥 경계

UTF-8 문서의 첫 줄은 `<!-- SESSION:V1 -->`다. `CURRENT`, `R1`, `R2`, `R3`, `R4`를 각각 한 번 둔다. 각 구획은 아래와 같이 원문 밖의 경계와 줄바꿈으로 감싼다. 구획 안은 원문 그대로이며 제목·목록·표·코드·끝 공백을 바꾸지 않는다. 원문의 마지막 줄바꿈과 별도로 끝 경계 앞에 감싸는 줄바꿈 하나를 둔다.

```text
<!-- SESSION:BEGIN R1 -->
[확정 산출물 전체 원문]
<!-- SESSION:END R1 -->
```

첫 줄·구획 사이에는 다른 관리 내용을 두지 않는다. `CURRENT`에 현재 위치·다음 행동·잠정·미결정·증거 참조·원문 출처를 둔다. 확정 산출물은 R1~R4에만 보존하며 현재 상태에서 요약 정본으로 복제하지 않는다. 아직 확정하지 않은 단계는 `미확정`과 확인할 근거를 적는다. 확정 산출물 안의 미확인·잠정 조건을 확정 사실로 바꾸지 않는다. 과거 원문의 당시 상태 표현과 현재 유효한 승인·후속 교정은 구별한다.

`<!-- SESSION:` 문자열은 바깥 경계 전용이다. 원문에 이 문자열이 있으면 원문을 조용히 바꾸지 말고 충돌을 알리고 규격을 조정한다. 손상·누락·중복 경계는 일부 추출로 통과시키지 않는다.

## 갱신과 동시 수정

기존 문서를 읽고 SHA-256을 확보한 뒤 바꿀 구획의 전체 원문을 준비한다. 이 Skill 내부 `scripts/session-document.mjs`가 제공하는 `readRegularFile`, `digest`, `replaceBlock(documentPath, blockId, body, expectedHash)`를 사용해 구획을 교체할 수 있다. `replaceBlock`은 `SESSION.md.lock`을 배타 생성하고 읽은 버전을 대조한 뒤 다른 구획을 그대로 둔 전체 문서를 임시 파일→원자적 교체로 저장한다. 의미·확정·권한 판단은 이 함수가 하지 않는다.

잠금이 이미 있거나 버전이 달라졌으면 덮어쓰지 말고 현재 문서를 다시 읽어 조정한다. 중단된 작성자의 잠금은 작성 중이 아님을 확인한 뒤에만 회수한다. 다른 작성 경로도 같은 잠금·버전 대조를 지켜야 한다. 외부 편집기가 이 규약을 무시한 동시 쓰기까지 막는 파일 시스템 보안 장치는 아니다. 메인이 통합 정본을 관리하고 분기는 메인 문서를 직접 수정하지 않는다.

R1~R3 확정 변경은 해당 구획을 갱신하고 하위 기준에 대한 영향을 CURRENT에 표시한다. R4는 실제 결과 후 완료·현재 위치·남은 실행 구조를 갱신한다. 합의한 목표·계약·권한·멈춤 변경은 해당 단계의 사용자 판단을 따른다. 여러 구획 변경은 필요하면 같은 잠금 아래 읽은 버전을 대조해 전체를 원자적으로 교체하고 다른 원문을 대조한다.

## 전달과 복원

시작·재개·맥락 압축 후·합의 원문 누락/잘림·상태 충돌에는 해당 세션의 SESSION을 직접 확인한다. 현재 완전한 최신 원문이 이미 문맥에 있으면 중복 조회하지 않는다. 의미 있는 결과와 승인·조건 변경을 저장한 뒤 현재 요청·유효한 승인과 대조한다. Hook 설정·이벤트 runner와 `.session-context.json` 출력 캐시는 이 시험팩에서 사용하지 않는다. 공통 진입 지침은 자동 이벤트 실행·복원을 보장하지 않는다.

완전한 최신 원문이 실제로 문맥에 있으면 중복 조회하지 않는다. 누락·잘림·구획 손상·읽기 실패는 알리고 전체 원문을 직접 확인해 영향받는 실행의 공백을 보완한다. 범용 helper의 기본 읽기·갱신 한도는 UTF-8 256 KiB이며 성공 기준·분량 목표가 아니다. 초과 원문은 축약하지 않는다. 같은 잠금·버전·원문 보존 규약을 지키는 처리 방식을 확인하기 전에는 helper 한도를 넘긴 갱신을 수행하지 않는다.

구형 SESSION을 자동 덮어쓰거나 R4.md를 자동 상속하지 않는다. 전환 전에 SESSION·기존 단계 문서·대화의 확인 가능한 원문과 사용자 정정을 대조하고 복구본을 보존한다. 정확한 원문이 없으면 미확인으로 남기고, 새로 조합한 복원안을 기존 확정 원문이라고 주장하지 않는다. 확인한 전체 산출물을 SESSION으로 옮겨 대조한 뒤 기존 R4.md의 현행 정본 역할을 종료한다. 원본은 역사·복구 자료로 보존하며 두 현행 정본을 유지하지 않는다. 모든 과거 세션을 일괄 전환하지 않는다.
