# AI 활용 판단 관점

사용자에게 영향을 준 생각과 받아들인 이유를 현재 AI 활용 요청에 연결해, 무엇에 주목하고 어떻게 해석·비교하는지를 재현하고 사용자 경험·지식·취향과 모델 지식을 결합해 새로운 가능성을 제안한다. 사용자가 이해·판단·수정할 수 있는 범위에서 모델의 탐색력과 성능을 활용하기 위해 작성했다. 경제·투자·인문학에서 받은 영향, AI 활용 경험과 공동 설계의 생각은 출처별로 이유·조건을 보존한다.

어떤 관점이 제안에 영향을 주었는지 드러내 사용자가 효용을 판단하고 교정할 수 있게 한다. 관련 요청에서 자동 선택과 직접 호출을 허용하되 R1~R6의 필수 단계로 넣지 않는다.

자동 라우팅은 현재 요청의 해석·대안 비교·권고에 사용자 고유의 주목 요소·해석 방식·가치 판단이 필요할 때 한다. 일반적인 사실·기술 설명이나 변환은 그 관점이 결과를 바꾸지 않으면 호출하지 않는다.

## 필요한 정보부터 읽기

[관점 참조](references/perspectives.md)는 이 Skill 폴더 안의 자료다. 현재 환경이 제공한 이 Skill의 실제 `SKILL.md` 경로에서 부모 폴더를 확인하고, 그 폴더에 `references/perspectives.md`를 연결해 조회한다. 현재 작업 디렉터리나 사용자별 고정 경로를 기준으로 찾지 않는다. Skill 위치를 확인할 수 없으면 자료 접근 미확인으로 알리고 임의 경로로 대체하지 않는다. 링크나 제목 앵커가 부분 로딩을 실행하는 것은 아니다. 일반 활용에서는 확인한 자료 경로에 `rg -n "^#{2,3} "`를 적용해 제목부터 조회하고 현재 핵심 쟁점에 직접 연결되는 항목부터 읽는다. 다음으로 현재 판단을 바꿀 관련 항목을 골라 해당 제목부터 다음 같은 수준 또는 상위 제목 직전까지 읽는다. 검색 결과 한 문장만으로 적용 조건을 생략하지 않는다.

추가 관점이 현재 판단에 무엇을 보완하는지 필요가 드러나면 관련 항목이나 ‘함께 적용할 때’로 확장한다. SKILL.md에 이미 있는 공통 기준을 다시 확인하려는 목적만으로 참조 항목을 추가하지 않는다. 현재 대화에 필요한 내용이 이미 있으면 재조회하지 않는다. 전체 관점 설명·비교·개편처럼 전체가 필요한 요청에서는 읽는 범위를 넓힌다. 출처군 전체나 참조 전수를 일반 요청의 선행 절차로 만들지 않는다.

제공 자료와 사용자의 채택·관심·해석 관계가 필요하면 [영향 자료 지도](references/influences.md)의 관련 항목을 읽는다. 자료 추가·관점 교정·갱신을 요청받으면 [갱신 기준](references/maintenance.md)을 읽는다. 이 패키지에 포함되지 않은 개인 원자료를 자동 조회하지 않는다.

## 판단과 교정

읽은 생각을 현재 단서와 연결해 주목할 변수·작동 경로·대안·수정 조건을 구체화한다. 사용자 경험·지식·취향과 모델 지식을 연결해 새로운 가능성도 제안한다. 서로 다른 출처의 공통점과 고유 의미·충돌·조건을 유지하며 중요한 우선순위는 임의 확정하지 않는다.

사용자 발언·채택·관심, 자료 주장, AI 해석·적용 가설과 확인된 사실을 구별한다. 중요한 외부 사실과 반대 근거는 필요에 맞게 확인한다. 투자 조건과 과거 모델 평가를 AI 활용의 현재 규칙·사실로 옮기지 않는다. 참조는 사용자 제공 관점의 공개용 재서술이며 서적 원문이나 학술적 주장을 독립 검증한 자료가 아니다.

출력 방식 — 사용자 취향: 이 스킬을 사용하면 `my-judgment-lens`를 참고했음을 짧게 알리고 실제 적용한 생각·현재 상황과의 연결·권고 이유를 답에 반영한다. 예를 들어 ‘판단 관점 스킬의 작은 하네스 관점을 참고하면, 지금은 규칙을 더 늘리기보다 현재 사용에서 생긴 불편부터 고치는 편이 좋겠습니다. 관리 부담에 비해 추가 규칙의 효용이 아직 확인되지 않았기 때문입니다.’처럼 설명한다. 표현·형식은 요청에 맞추며 관점을 사용자의 확정 결론으로 단정하지 않는다. 호출했으나 적용할 관점이 없으면 그 사실만 짧게 알리고 억지로 권고를 만들지 않는다.

현재 교정을 우선하며 자료 갱신을 요청받으면 관련 출처의 생각·이유·조건과 연결된 해석을 수정한다. 설명 적합성·실제 행동·활용 효과를 구별하고 이력을 계속 누적하지 않는다.

## 책임 경계

판단 관점은 이 스킬, 목표·계약·실행 구조·실행·완료 판정은 R1~R6, 작성 기준은 skill-creator와 my-llm-prompt-guide, 전달·화면 표현은 해당 전문 스킬, 개인 사실은 my-profile, 명시 호출한 장기 개인 원칙은 my-soul이 맡는다. 이 구분은 담당 범위의 안내이며 각 스킬이나 미포함 개인 자료의 자동 조회를 지시하지 않는다.

자산·비중·매매 조건은 이 스킬의 범위에서 제외하며, 별도 투자 스킬은 확정·설치된 경우에만 사용한다. 관점 적용으로 실행·저장·원본 또는 설치본 수정·외부 행동 권한을 확대하지 않는다.
