# 팔레트·본문 스타일과 근거

## 본문 스타일

아래는 2026-10-05 사용자가 지정한 재사용 기준이다. 색상 측정 기록과 구별하며, 이 요청에서 GPT 전체 화면의 타이포그래피를 추가 측정한 것으로 소개하지 않는다.

| 항목 | 기준 | CSS |
| --- | --- | --- |
| 본문 | 16px / 행간 26px | `font-size: 16px; line-height: 26px` |
| 기본 자간 | 브라우저·폰트 기본값 | `letter-spacing: normal` |
| 소제목 | 18px / 행간 28px / 굵기 600 | `font-size: 18px; line-height: 28px; font-weight: 600` |
| 강조 | 굵기 600 | `strong { font-weight: 600 }` |
| 문단 간격 | 16px | 문단 아래 간격 16px, 마지막 문단은 0 |
| 소제목 아래 | 4px | `margin-bottom: 4px` |
| PC 본문 폭 | 최대 640px | `width: min(640px, 100%)` |

[본문 CSS](reading.css)는 기존 글꼴을 상속한다. 좁은 화면에서는 컨테이너 가용 폭에 맞추고, 화면 바깥 여백은 대상 UI의 규칙을 따른다. 굵기 600은 이미 지정한 소제목·강조에 적용하며 모든 문장에 자동 강조를 추가하지 않는다. 문단 간격이 중복되지 않도록 대상 CSS의 기존 margin/gap과 대응한다.

## 확보 범위

확보일: 2026-10-04. 대상: Windows Chrome의 chatgpt.com.

- 다크: 사용자 제공 홈 PNG와 실제 홈·기존 답변의 computed style, SVG 경로, before/after, 배경·그라데이션·테두리를 대조했다.
- 밝은 모드: 실제 페이지 CSSOM의 theme 정의를 가져와 로컬 표본에 `chatgpt-theme`, `data-theme=light`, `data-codex-window-type=browser`, 관찰된 contrast 60 조건을 적용하고 브라우저 계산값을 확인했다. 실제 밝은 홈·답변 전체를 직접 측정한 것은 아니다.
- 미노출 메뉴, 오류·성공 상태, 다른 계정·색상 테마, 모든 반응형 화면은 미확인이다. 밝은 코드 컴포넌트의 최종 겹침도 미확인이다.

본문의 굵은 글자도 같은 본문색이다. 측정 당시 출처 칩의 #303030을 사용자 말풍선으로 해석했던 것을 바로잡았다. 파일 아이콘 #0285FF는 관찰된 첨부 경로이며 일반 링크의 표준색으로 확대하지 않는다.

## 알파·겹침

- 다크 홈 활성 아이콘: 흰색10%가 검정 위에 겹쳐 약 #1A1A1A. 코드면: 흰색10%가 #0E0E0E 위에 겹쳐 약 #262626.
- 다크 인라인 코드: `color(srgb 0.965048 0.965048 0.965048 / 0.121176)`가 읽기 면에 겹쳐 약 #2A2A2A.
- 다크 진행 안내: `oklab(0.946099 0.0000428557 0.0000189543 / 0.6)`.
- 다크 탐색 보조 레이어: `oklab(0.163757 0.00000747293 0.00000327826 / 0.65)`.
- 다크 아래 페이드: `linear-gradient(to top in oklab, rgb(14,14,14) 0%, rgba(0,0,0,0) 100%)`.
- 밝은 보조 hover/active: 검정5/10%. 활성 탭 그림자: `0 1px 6px 0 rgb(0 0 0 / 5%)`. 현재 파란 선택 영역: #539AF859.
- 밝은 중성 말풍선 분기의 `rgb(233 233 233 / 50%)`와 파란 browser 조건의 최종 말풍선을 섞지 않는다. 후자는 사용자 선택 테마 사례다.

## 재사용 시 구별

측정 토큰과 대상 UI의 역할 대응을 구별한다. 예를 들어 서고의 작은 글자 버튼에는 밝은 주요 조작색 #3A83F7 대신 측정된 강조색 #2C67C5/흰색을 사용할 수 있다. 이는 대비를 확보한 대상 UI 대응이며 GPT 버튼 역할을 그대로 복제했다고 설명하지 않는다. 일반 본문에 #8F8F8F를 적용하지 않는다.

측정 토큰과 사용자 지정 본문 기준을 구별한 휴대용 리소스입니다. 원측정 프로젝트와 캡처는 이 패키지에 포함하지 않습니다.
