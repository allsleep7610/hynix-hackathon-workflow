### UDP-05 무채색 중심 색상 비율

- 범위: 앱, 웹, 대시보드, 보고서와 프로토타입의 기본 UI
- 사용자 표현: `무채색 80~90, 포인트 컬러 10~20 정도의 비중이 딱 좋은 것 같다.`
- 원칙: 화면의 시각적 무게는 무채색 80~90%, 포인트 컬러 10~20%를 기본값으로 삼는다. 무채색은 구조, 배경과 본문을 담당하고, 포인트 컬러는 주요 행동, 현재 선택과 의미 있는 상태에만 배정한다.
- 적용하지 않을 범위: 사진·일러스트가 주인공인 화면, 여러 범주를 색으로 비교해야 하는 데이터 시각화, 경고·오류처럼 의미 색이 필수인 상태에는 비율을 기계적으로 강제하지 않는다.
- 품질 검사: 화면을 빠르게 훑었을 때 무채색 구조가 먼저 안정적으로 읽히고, 포인트 컬러가 1~3개의 우선 행동이나 상태로 시선을 모아야 한다. 80~90/10~20은 픽셀 계산이 아니라 시각적 무게를 점검하는 범위로 사용한다.
- 확정일: 2026-07-19

## 갱신 형식

새 원칙은 다음 필드를 사용한다.

- stable id
- 적용 범위
- 사용자 표현 또는 반복 근거
- 원칙
- 적용하지 않을 범위
- 품질 검사
- 확정일 또는 마지막 갱신일

같은 판단이면 새 항목을 만들지 말고 기존 항목을 갱신한다. 충돌하는 피드백은 예외 문장을 누적하지 말고 현재 원칙의 범위나 내용을 다시 결정한다.
