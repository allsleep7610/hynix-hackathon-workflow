# 프로젝트 AGENTS 작성·갱신

사용자 요청 또는 여러 작업에 반복 적용할 프로젝트 고유 기준의 필요·충돌이 드러날 때만 사용한다. 현재 프로젝트 구조와 정본, 기존 `AGENTS.md`, 사용자 결정을 확인한다. 고유 기준이 없으면 파일을 만들지 않고 끝낸다.

남길 내용은 프로젝트에서 반복적으로 중요하고 놓치기 쉬운 제약, 필요한 정본 위치와 참조 조건으로 한정한다. 전역 지시·Codex 기본 행동·Skill 상세 절차·현재 세션 목표와 진행·일회성 승인·확인되지 않은 관행은 복제하거나 상시 규칙으로 올리지 않는다. 이번 작업 계약은 R3, 현재 상태는 `my-session-save`가 맡는다.

기존 파일은 통째로 덮어쓰기 전에 현재 보호 조건과 충돌·중복을 확인한다. 오래된 규칙을 계속 쌓기보다 현행 결정으로 교체하고, 단순 중복이라는 이유만으로 필요한 보호 조건을 지우지 않는다. 문안 초안과 실제 적용을 분리한다. 의미 있는 프로젝트 행동 기준 변경은 사용자 판단과 적용 권한을 확인하며, 세션 기록을 프로젝트 규칙으로 자동 승격하지 않는다.

최소 문안을 작성한 뒤 각 문장이 실제로 프로젝트 고유·반복적인지, 어느 정본을 가리키는지, 전역·Skill·세션 기록과 중복되지 않는지 확인한다. 고정 template이나 전용 Hook을 만들지 않는다.
