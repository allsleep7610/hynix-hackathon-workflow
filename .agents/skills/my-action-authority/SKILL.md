# 행동 권한 판단

실제 행동 직전에 그 대상·행동·범위·중요 조건이 현재 요청 또는 유효한 사전 승인에 포함되는지 확인한다. 모든 작업에 긴 승인 양식을 요구하지 않는다. 사용자가 원하는 결과에 동의한 것과 삭제·외부 전송·배포처럼 특정 대상에 행동할 권한을 받은 것은 다르다. 단계 이동, Skill 호출, 기술적으로 도구 사용 가능함, 기록 작성은 새 승인이 아니다.

- **진행 가능:** 현재 행동이 승인된 대상·행동·범위·조건 안에 있다. 단계가 바뀌거나 다음 도구를 쓴다는 이유만으로 다시 묻지 않는다.
- **사용자 확인 필요:** 중요한 대상·행동·범위·조건이 달라졌거나 승인 여부가 불명확하다. 해당 행동과 의존 작업을 보류하고 정확히 무엇을 새로 결정해야 하는지 묻는다. 영향받지 않는 승인 작업은 이어갈 수 있다.
- **실행 불가:** 사용자 승인 밖이거나 상위 권한·보안·도구 제한에 막힌다. 사용자 승인도 기술적 제한을 우회하지 않는다.

사용자가 새 승인, 승인 범위 조회, 철회, 조건 변경을 요청하면 실제로 결정된 대상·행동·범위·조건을 현재 유효한 상태로 정리한다. 다른 세션의 일회성 승인을 자동 상속하지 않는다. 사용자가 지속 적용을 명시한 사전 합의는 담당 Skill의 대상·행동·조건과 이후 변경·철회를 대조해 적용한다. 지속 합의는 담당 Skill에, 세션만의 승인과 중요한 제외·조건은 `SESSION.md`의 확정 구획에 남기고, 정확한 대상·행동·범위가 R3 계약에 있으면 최소 참조만 남긴다. 세션 기록은 `my-session-save`가 수행하며 이 Skill이나 기록이 승인을 만들어내지 않는다. 승인 대화 전체나 일회성 사례를 이 Skill 본문에 축적하지 않는다.

R3는 계약의 허용·제외 행동, R4는 새 승인 판단 지점, R5는 실제 행동의 승인 포함 여부, R6는 준수 여부를 각자 다룬다. 이 Skill은 그때 사용할 공통 판단 기준만 소유한다. 사용자 방향 변경에 필요한 확인과 실행 권한 확인을 혼동하지 않고 계약 안 기술 보정에 불필요한 승인 절차를 추가하지 않는다.
